Research directions: Man Ngo

Man Ngo (HCMUS) · All professors

Neural architectures and memory models aimed at generalizing beyond the training distribution, through indirection and pseudo-inverse memory. Work on plug-in layers and memory-based networks that abstract relations between objects to generalize to unseen classes and transformations. Work on fast generative memory models that write and read data through iteratively approximated matrix pseudo-inverses, supporting retrieval, denoising and sample generation.

Open challenges. Work on generalizing to unseen rules and natural images, with memory cost for deep backbones and backbone design still open. Work on comparisons with modern variational approaches and on firmer empirical evidence for the reported gains.

Deep learning and representation learning (2 papers · CSRankings score 0.50)

Topic description

Both papers study out-of-distribution generalization using indirection, in which a representation refers to stored trainable symbols or weights instead of the data itself. One adds a layer that builds relation graphs over an input sequence; the other composes backbone weights on the fly from a memory of basis weight matrices. They report gains on IQ-style tasks, and the layer is also tested on distorted image classification and few-shot NLP classification.

Papers (2)
Improving Out-of-distribution Generalization with Indirection Representations ICLR 2023 · accepted
The problem
Neural networks generalize poorly out of distribution (OOD): unseen samples with very different surface statistics from the training data.
The idea
A generic plug-in layer that treats an input sequence of objects as a complete weighted graph whose edge weights are relationships between objects. The input is mapped via indirection (referring to a stored symbol instead of the data itself) to a symbolic graph with data-independent, trainable vertices, which is then propagated to give new vertex features used for prediction.
Strengths
The paper proves that distances between indirection representations are bounded by distances between the corresponding graphs. It reports consistent OOD improvements on IQ problems, distorted image classification and few-shot domain adaptation for NLP classification, with ablation studies of design choices.
Questions raised by reviewers
  • It is not clear at this point whether InLay can capture implicit and complex relations between natural images.
  • I believe there should be experimental settings where the input sequence is large.
  • The standard deviation numbers provided in the appendix are fairly high across the board.

Functional Indirection Neural Estimator for Better Out-of-distribution Generalization NeurIPS 2022 · accepted
The problem
OOD generalization on IQ-style tasks: infer a hidden geometric transformation from an input-output image pair and apply it to a new image whose class was not seen in training.
The idea
Analogy-making and indirection are performed in function space rather than data space. A backbone network has its weights built on the fly by mixing the basis weight matrices of a trainable semantic memory, with mixing coefficients computed by querying a separate memory with the input-output pair.
Strengths
Trained on IQ tasks built from MNIST, Omniglot and CIFAR100 and tested on unseen image classes from the same or different datasets and on unseen transformation rules, it reports the best performance on all tasks and adaptation to small-scale data. The authors also report that with the invertible-network backbone accuracy peaks near 85% at 100,000 training points, while with a 2-layer MLP backbone it reaches about 95% at 1M points.
What the authors leave open
  • The memory stores several trainable weight matrices for each backbone layer, so very deep backbones may need a large number of parameters; the authors suggest parameter sharing across layers and limiting the rank of the matrices.
  • The best backbone architecture remains to be designed; accuracy trends differ between backbones as training data grows, which calls for further theoretical analysis to guide the design.
  • Testing only on visual IQ tasks may limit the potential on other modalities such as textual analogy problems.
Questions raised by reviewers
  • The newly introduced datasets test generalization only for the unseen characters of the training dataset but not for unseen rules that could be extrapolated or interpolated.
  • The proposed method may need a large memory to store trainable weights for very deep backbones.
  • However, the method is not evaluated on the known abstract reasoning benchmark of PGMs.
  • The hard challenge in IQ tests is to generalize to novel rules.

Generative models (1 paper · CSRankings score 0.17)

Topic description

This paper recasts memory writing and reading in a generative model as solving linear systems with iteratively approximated matrix pseudo-inverses. It proves exact retrieval of written data under mild conditions and uses iterative reading for denoising and generation. Experiments cover binarized MNIST and Omniglot, FashionMNIST, CIFAR10, CIFAR100 and CelebA.

Papers (1)
Generative Pseudo-Inverse Memory ICLR 2022 · accepted
The problem
Deep generative memory models (in the Kanerva machine line) are slow to write into and read from, which limits how much data they can store.
The idea
Memory operations are recast as seeking robust solutions of linear systems, solved with matrix pseudo-inverses that are approximated iteratively, with practical computation complexity of almost O(1). Iterative reading enables attractor dynamics toward fixed points, improving sample quality in denoising and generation.
Strengths
The paper proves and verifies empirically that the model retrieves exactly what was written under mild conditions, and reports storing large amounts of data while retrieving patterns, denoising corrupted data and generating novel samples. Experiments use binarized MNIST, binarized Omniglot, FashionMNIST, CIFAR10, CIFAR100 and CelebA.
Questions raised by reviewers
  • This study also warrants proper comparisons to modern variational approaches.
  • I found the empirical results questionable.
