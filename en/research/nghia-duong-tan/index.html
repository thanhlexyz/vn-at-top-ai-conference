Research directions: Nghia Duong Tan

Nghia Duong Tan (HUST) · All professors

Recommendation methods that combine user ratings with item content while limiting the personal data needed. Work on hybrid neighborhood-based recommendation adds user-item similarity scores, computed from users' past ratings and item features, as a correction to collaborative filtering predictions.

Open challenges. Work on hybrid neighborhood-based recommendation leaves open evaluation on more datasets, ranking metrics and stronger baselines, plus the added running time.

Topic description

Hybrid recommendation systems combine interaction data with item content, but they need large amounts of user data, which raises privacy concerns. The paper proposes methods that use the baseline estimate of a rating to learn each user's interest in specific item features from past interactions, and uses the resulting user-item similarity as an extra factor in neighborhood-based collaborative filtering. It reports at least 2.11% higher accuracy than traditional methods on rating prediction.

Papers (1)
Incorporating User-Item Similarity in Hybrid Neighborhood-based Recommendation System ICLR 2022 · rejected
The problem
Hybrid recommendation systems need large amounts of data to understand user interests, but internet privacy concerns make users reluctant to share personal information with service providers.
The idea
Novel methods that use the baseline estimate to learn user interests in specific item features from past interactions; the extracted user feature vectors give user-item correlations that act as an additional fine-tuning factor in neighborhood-based collaborative filtering.
Strengths
Experiments report that using the user-item similarity scores in rating prediction improves the accuracy of hybrid neighborhood-based systems by at least 2.11% compared with traditional methods; in the paper text, one variant reaches 4.80% lower RMSE and 4.88% lower MAE than the original kNNBaseline.
What the authors leave open
  • Future work will extend the application of user-item correlations to other collaborative filtering approaches.
Questions raised by reviewers
  • The paper evaluates its method on only one dataset, MovieLens20M.
  • To my knowledge, recommender system community is more interested in ranking based metric such as mAP and NDCG.
  • The baseline methods used in experiments are too simple.
  • the proposed user feature vectors have about 3 times more running time than the current method, but the time complexity of the proposed methods is not provided.
