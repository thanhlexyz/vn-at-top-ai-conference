Research directions: Nguyen Thi Hanh

Nguyen Thi Hanh (Phenikaa) · All professors

Prof. Hanh's papers study systems that improve themselves from feedback, using large language models or writable memory. Work on LLM-guided heuristic evolution lets an LLM refine groups of related heuristics for combinatorial optimization over several turns, using performance feedback. Work on recommenders that adapt through writable memory keeps model parameters frozen and stores stable knowledge-graph facts plus recent failures and lessons.

Open challenges. Work on multi-turn LLM heuristic refinement leaves open whether it helps beyond online bin packing, which of its parts matter, and what its computation costs. Work on memory-based adaptive recommendation leaves open the extra storage and computation cost, wider quality-gate settings, and evaluation beyond reranking sampled candidates.

Optimization methods (2 papers · CSRankings score 0.29)

Topic description

Heuristics for NP-hard combinatorial optimization are clustered by behaviour or performance profile, and an LLM critiques and refines each group over several turns with accumulated feedback. One paper reports reducing the optimality gap to nearly 9% where variants without multi-turn reflection plateau near 18%, and the other reports lower optimality gaps than one-shot LLM code generation and genetic programming on online bin packing.

Papers (2)
ReVEL: Multi-Turn Reflective LLM-Guided Heuristic Evolution via Structured Performance Feedback EMNLP 2026 · rejected
The problem
Designing heuristics for NP-hard combinatorial optimization problems needs domain expertise, and LLM-guided evolutionary methods mostly refine each heuristic on its own or with pairwise feedback.
The idea
ReVEL groups heuristics by behaviour, into similarity-driven groups for local refinement and diversity-driven groups for exploration, and has the LLM refine each group over several turns using accumulated performance feedback.
Strengths
The paper reports improvements over LLM-guided evolutionary baselines on standard benchmarks and several LLM backbones; in its cost analysis, variants without multi-turn reflection plateau at an optimality gap of about 18% while ReVEL reaches nearly 9%.

Cognitively Inspired Reflective Evolution: Interactive Multi-Turn LLM–EA Synthesis of Heuristics for Combinatorial Optimization ICLR 2026 · rejected
The problem
Reviewers describe the paper as targeting automated heuristic design for combinatorial optimization, where LLMs are typically used as one-shot code generators inside evolutionary algorithms.
The idea
According to the reviews, CIRE clusters candidate heuristics by performance profiles and CodeBLEU code similarity, forms similar and mixed groups for the LLM to critique and refine over several turns, and lets an evolutionary-algorithm meta-controller validate the proposals.
Strengths
Reviewers summarise experiments on online bin packing that report lower optimality gaps and excess-bin fractions than one-shot LLM code generation, genetic programming and evolutionary algorithms without LLM feedback.
Questions raised by reviewers
  • The authors claim the proposed method is for “CO”, but actually only for the bin packing problem.
  • There is no ablation isolating the effects of clustering, entropy-based grouping, or reflective multi-turn reasoning on performance. The improvement could stem from increased prompt diversity rather than the proposed reflective mechanism.
  • The computational cost of multi-turn LLM reasoning is not reported.
  • The results rely solely on a single proprietary model (DeepSeek V3), with no comparison across different LLMs or open-source baselines, hindering reproducibility.

Data mining and graph learning (1 paper · CSRankings score 0.20)

Topic description

Knowledge-graph-enhanced recommenders usually read the graph as a static source, which the paper argues makes them brittle when user intents drift. The proposed method turns recommendation outcomes into quality-gated, typed edits of a semantic graph memory and records recent failures and corrective hints in a separate episodic memory, keeping model parameters frozen at test time. The paper reports gains over neural and LLM-based baselines on most metrics, including up to 29.58% higher HR@1 than the strongest LLM baseline on one dataset.

Papers (1)
Continual Graph Memory for Adaptive Recommendation under Intent Drift EMNLP 2026 · rejected
The problem
Recommenders must adapt when user intents drift, but knowledge-graph (KG) enhanced systems treat the graph as a static retrieval source, which the paper says makes them brittle to evolving intents, noisy metadata and recurring failure patterns.
The idea
CGM-Rec treats the graph state as writable memory with two parts: a Semantic Graph Memory updated conservatively through quality-gated typed edits for stable relational knowledge, and an Episodic Lesson Memory that records recent outcomes, failure cases and corrective hints; model parameters stay frozen at test time and adaptation happens only through memory writes.
Strengths
Under a frozen-parameter, one-pass reranking protocol, the paper reports improvements over neural and LLM-based baselines on most metrics, including up to 29.58% higher HR@1 than the strongest LLM baseline on Bundle and HR@5 of 0.5941 versus 0.4746 for K-RagRec on ML-100K.
What the authors leave open
  • CGM-Rec adds complexity over static retrieval, requiring extra storage and computation to maintain its memories.
  • The quality gate is shown to be robust only to moderate perturbations; broader gate configurations and typed update magnitudes remain unexplored.
  • Evaluation focuses on sampled-candidate reranking, with candidate pools of 50 and 80 items used as larger-pool robustness tests.
