Topic description

Finding an allocation of indivisible goods that is both fair and efficient is computationally hard. The paper models it as a bi-criteria problem over max-min fairness and utilitarian efficiency and builds an approximate Pareto set of bounded size, using either a dynamic programming scheme or a linear-programming algorithm, for instances with few item types or few agent types. It shows both constructions run in polynomial time, and one result answers an open problem from machine scheduling.

Papers (1)
Approximate Pareto Set for Fair and Efficient Allocation: Few Agent Types or Few Resource Types IJCAI 2020 · accepted
The problem
When indivisible goods are divided among agents, finding an allocation that is both fair and efficient is computationally hard, yet it is the outcome one usually wants.
The idea
The paper treats the task as a bi-criteria optimization of max-min fairness (maximising the worst-off agent's utility) and utilitarian efficiency (maximising total utility), and computes an approximate Pareto set of bounded size with dynamic programming or a linear-programming algorithm when there are few item types or few agent types.
Strengths
The paper shows that in both settings an approximate Pareto set can be constructed in time polynomial in the input size, and its result on min-max allocations for a constant number of item types answers an open problem raised by Jansen and Maack (2019) in machine scheduling.
What the authors leave open
  • The polynomial-time results hold only when the number of item types or the number of agent types is small.
  • The authors state that their techniques could potentially be applied to notions of fairness and efficiency other than max-min fairness and utilitarian efficiency.
