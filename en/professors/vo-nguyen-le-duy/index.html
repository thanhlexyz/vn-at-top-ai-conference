Vo Nguyen Le Duy

Lecturer, University of Information Technology, VNU-HCM. Affiliated with a Vietnamese university since 2024.

Selective-inference hypothesis tests that attach valid p-values to regions flagged by deep anomaly-detection and attention models. Work on valid p-values for detected regions in image anomaly detection and attention maps, using selective inference to control false positive rates.

Open challenges. Work on selective-inference tests for detected image regions still relies on piecewise-linear networks, mean-based test statistics and high computational cost.
