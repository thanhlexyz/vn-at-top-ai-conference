Phat T. Tran-Truong

Lecturer, Ho Chi Minh City University of Technology, VNU-HCM. Affiliated with a Vietnamese university since 2024.

Prof. Phat's papers study reliability, privacy and cost of machine learning systems, mostly through controlled studies including negative results. Work on memory transfer between language-model agents and on privacy accounting, deletion and action gating, so guarantees survive restarts and model upgrades. Work on synthetic data for African languages tests whether synthetic examples rated highly by an LLM judge actually help classification in low-resource languages. Work on routing LLM code to cheaper languages measures cost-quality trade-offs when the target programming language is chosen before generation, with fallback when tests fail.

Open challenges. Work on memory migration between language models leaves open whether risk depends on the model pair, guarantees outside simulators, unmet proof assumptions and unvalidated labels. Work on synthetic data for African languages leaves open whether gains come from quality filtering or set size, ordering beyond three seeds, and GPU cost. Work on routing LLM code to cheaper languages leaves open whether cost savings hold once reasoning tokens, retries and a terse Python prompt are counted.
