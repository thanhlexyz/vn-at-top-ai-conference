Thanh Pham Chi

Lecturer, RMIT University Vietnam. Affiliated with a Vietnamese university since 2011.

Prof. Thanh's recent paper studies the safety of language-model agents whose memory moves from one model to another. Work on memory transfer between language-model agents examines whether memory that is safe for one model triggers harmful behavior in another after migration.

Open challenges. Work on memory migration between language models leaves open whether risk is a property of the model pair rather than of the target model alone.
