Huynh Quyet Thang

Associate Professor, Director, Hanoi University of Science and Technology; Member of the 16th National Assembly, Hanoi University of Science and Technology.

Prof. Thang's recent papers apply machine learning and large language models to software engineering tasks. Work on evaluating LLM code in functional languages benchmarks Haskell, OCaml and Scala on correctness, code style and maintainability. Work on identifying libraries affected by vulnerabilities casts the task as knowledge graph completion over a graph linking vulnerabilities, libraries and weakness types.

Open challenges. Work on LLM code generation in functional programming leaves open generalization to other functional languages and a self-repair evaluation that covers every model. Work on matching vulnerabilities to affected libraries leaves open newly introduced libraries with little history, confusable libraries and packages redistributed across ecosystems.
